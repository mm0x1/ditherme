# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through the repository's
security advisory feature or by contacting the maintainer through the email
listed in `package.json`. Include enough detail to reproduce the issue, the
affected version, and any proof-of-concept material that can be shared safely.

Do not open a public issue for an unpatched vulnerability.

The scripting API is disabled in the alpha release. Reports involving the
Electron add-on, native file dialogs, renderer injection, or packaged update
artifacts are especially useful.
